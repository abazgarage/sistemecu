# NADI — Automotive Intelligence

NADI is a futuristic automotive ECU learning and visualization lab built with Vue 3, Vite, and Three.js.

## Features
- Interactive 3D ECU board with orbit, zoom, and clickable component hotspots.
- Animated electrical signal paths and a live pulse indicator.
- Sensor/actuator inspector with educational descriptions.
- Diagnostic panel with sample DTC data (simulation only).
- Responsive holographic interface.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The 3D ECU is a conceptual educational model. It is not a vehicle-specific wiring reference or a tool for controlling a real ECU.
